
# Algoritmos - SmartRoute GT

## Introducción

Esta sección contiene la documentación de los algoritmos relacionados con el proyecto SmartRoute GT.

El objetivo es explicar el funcionamiento de diferentes algoritmos de búsqueda, ordenamiento, recorrido de grafos y toma de decisiones, así como su posible aplicación dentro del sistema de gestión y monitoreo de transporte.

## Algoritmos documentados

1. [Dijkstra](Dijkstra.md)
2. [BFS - Breadth-First Search](BFS.md)
3. [DFS - Depth-First Search](DFS.md)
4. [Búsqueda Lineal](BusquedaLineal.md)
5. [Búsqueda Binaria](BusquedaBinaria.md)
6. [Bubble Sort](BubbleSort.md)
7. [Merge Sort](MergeSort.md)
8. [Greedy](Greedy.md)

## Criterios de documentación

Para cada algoritmo se incluye:

- Objetivo.
- Explicación de funcionamiento.
- Pseudocódigo.
- Complejidad temporal mediante Big O.
- Complejidad espacial.
- Justificación de su posible aplicación en SmartRoute GT.
- Diagrama de flujo.

## Relación con SmartRoute GT

Los algoritmos se relacionan principalmente con operaciones que pueden aparecer en un sistema de transporte inteligente, como:

- Representación y recorrido de rutas y paradas.
- Búsqueda de información.
- Organización de datos.
- Determinación de recorridos.
- Selección de alternativas según determinados criterios.
- Procesamiento de información relacionada con buses, pilotos y rutas.

> Nota: La documentación diferencia entre los algoritmos que forman parte de la lógica documentada del proyecto y aquellos cuya utilidad se analiza como una aplicación apropiada para SmartRoute GT. No se afirma que un algoritmo esté implementado en Java si no existe evidencia de dicha implementación en el código del proyecto.
