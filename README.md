# SmartRoute GT

SmartRoute GT es un sistema inteligente de monitoreo y control de transporte público.

El sistema permitirá monitorear buses mediante GPS, administrar rutas y paradas, controlar el cumplimiento de límites de velocidad y registrar sanciones.

## Usuarios del sistema

El sistema contará con tres tipos de usuarios:

- Administrador
- Piloto
- Pasajero

## Aplicaciones

SmartRoute GT estará compuesto por:

- Aplicación móvil para pilotos y pasajeros.
- Plataforma web para administradores.
- Backend central mediante una API REST.
- Base de datos MySQL.
